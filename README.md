# blockErrorRate
Compare Hamming (7,4), Convolutional, and Low Density Parity Check Code encoding and decoding over binary symmetric channel

What started as a class project to implement Bernhard Leiner's example of LDPC decoding has led me to attempt implement an encoding and decoding scheme for three codes that we learned about in class. Note that these three codes do not have the same block code length, therefore their rates are different as well. This means their block error rate is not a fair comparison, but as an exercise it taught me a lot about how encoding and decoding can be doen.
